The latest user direction places Clementine **only in the hero**, with an idle
loop followed by a native-scroll document handoff. The rest of the website is
one continuous code-rendered journey following that document through the agent
loop, memory, tools, projects, specialists, Spaces and workflows.

## Playback and fallback

Native scrolling controls the handoff directly, including reverse scrolling.
The visitor never has to wait for a film to finish. The idle film loops while
reading; the handoff is manually sought and never autoplays. Pause freezes the
rendered hero progress and idle playback. Introductory controls become inert
when hidden. Reduced motion and data saving retain a settled still, skip video
requests and expose complete content in normal flow. The download remains
available without video. Final responsive behavior and browser playback are
separate integration checks from film acceptance.
