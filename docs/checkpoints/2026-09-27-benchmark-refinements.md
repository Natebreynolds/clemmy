2. **Memory has both job identity and causal task accounting.** Memory execution still clears the conversation's model-selection/execution scope. Nested jobs and own-request wrappers preserve the link without double recording. Scheduled jobs receive a unique job identity without inventing a user source. The canonical task meter already joins exact accepted-source traces, including work arriving after delivery; a regression test pins this. It cannot charge an unrelated draining chat or invent an attempt after restart. Legacy intake without a verifiable source remains unassigned rather than guessed.

Add the narrow history-only non-action disposition with exact objective/reply/source digests and positive no-current-work evidence. Review eligibility itself is unchanged. Publication without a matching receipt remains unavailable, never reviewed or not-required by inference. The live one-sentence symptom is consistent with this path; its exact installed rerun remains owed. The separate legacy self-contained-computation skip record is not changed in this wave.

Only this declared local status branch changes; set/add_rule/remove_rule, absent/unknown actions, foreign MCP lookalikes, and external writes retain their existing treatment. Direct and carried calls are covered. No heartbeat settings are changed.

5. **Memory-search result limits are real schema.** The benchmark's memory_search call requested limit, which its schema rejected.
