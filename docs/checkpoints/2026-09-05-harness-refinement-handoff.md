### Explicit Plan → Execute foundation (C8, inherited by C10)

Accepted task mode is typed and bound into durable identity:

```ts
taskMode?: { version: 1, kind: 'normal' | 'plan' }
  | { version: 1, kind: 'execute', executeRef: { planId, revision, digest } }
```

Omitted Normal retains legacy request hashing. English phrases do not select the mode. Desktop's automatic `runPlanFirstPreflight` was removed. Explicit addressed legacy proposal replies remain compatible.

Plan runs the configured loop with discovery, reads, compute and investigative workers. It cannot execute proposed business/native writes or acquire new business grants. `publish_plan` is a narrow host-artifact exception. Full immutable artifacts reject oversize content instead of silently truncating it (2MB total bound). A ready effectful plan retains the prepared action draft, exact refs, account/schema identities, static arguments, dependencies and producer bindings.
