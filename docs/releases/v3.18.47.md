# v3.18.47 — No more frozen half hours, one card for a batch, and an approval that ends in Clem's words

**Database migration: harness schema 98 → 99** (one new index on the session
list; nothing is rewritten). The Mac build comes from the release workflow
(signed and notarized). The Windows x64 build of the same commit is qualified
by the private Windows pipeline from this tag, **unsigned** until a
code-signing certificate exists.

## The app stays responsive

- **The half-hour freeze is gone.** Every chat send used to wait behind the
  daemon's own bookkeeping: each workflow step start re-read its run record
  under a lock, the "is anything closing?" walk ran on every tick, and a
  memory trace file was rewritten on every recall. The step start now reads
  without the lock, the walk is remembered for a minute, and the trace trims
  by count.
- **Nothing on disk is parsed twice.** A run record, the notification store
  or a background task file that has not changed since the last look is
  reused instead of re-read, so the Home poll stops costing a full scan.
- **The session list has an index.** Opening the chat list and a preview's
  change mark read two index edges instead of every event.

## Fewer taps, fewer waits

- **One card for a batch.** When one request needs several commands of the
  same kind, they open together as one card you answer once, instead of a
  card per command.
- **A rate-limited brain is switched away from on the first refusal.** With
  another brain configured behind it, the first "slow down" moves the turn
  across instead of waiting out a two-minute retry.
- **A write-constraint check reads long observations.** A scheduled sheet
  review that read a large Slack pull was refused by a size limit inside the
  check itself, which then asked the checker the same question for an hour.
  The check now digests at the sealed-call limits, and the same refusal three
  times ends the step with the reason said plainly.

## An approval is a yes, not a new task

- **An approved action ends in Clem's words.** After you tap a card, the
  reply says what ran, what it produced, and what the request still has
  left, instead of a silent "approved".
- **The resumed turn remembers the question.** A yes to "Shall I create these
  three drafts?" resumes as that request, with all of its calls issued in one
  step, never as a fresh task about the approval itself.

## Known

- The Windows beta is unsigned and installs with the usual SmartScreen step.
