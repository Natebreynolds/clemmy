# v3.17.0 — see what she's doing while she does it

Release type: desktop experience release on the 3.16.1 harness.

This release keeps the 3.16.1 harness as shipped and changes what you see of
it. Every place Clementine works now shows the work as it happens, the chat
home is a briefing, Settings is one page you can read, and Memory has one
search that explains itself.

## One activity card, everywhere

A turn, a Space build, a workflow run, and a background task all render the
same build log: a head with a live pulse and clock, each step with a plain
label and its duration, helpers as their own rows with the steps they report
nested underneath, the thinking line inside the card, and a results-first
one-liner once the work settles. Helpers' own steps now reach the chat: a
worker's tool calls used to land in a session nobody watched.

## Chat home is a briefing

What needs you, what is running, what finished while you were away, then the
composer. The panes follow your Home layout, so Customize still governs it,
and /home lands here. The rail shows conversations; runs live under Running.

## Spaces and workflows, watched live

A Space builds in a conversation column beside its canvas, with a revision
track and a "Nothing here yet" that gives way to the first version. Automate
shows which workflows are running and on which step, when the next one fires,
and opens a run to a live card above its step timeline. Runs started by cron or
the Run button stream for the first time. "Create with Clementine" opens a
creation view where the workflow takes shape as she writes it.

## Act and Plan, and a model chip

The composer modes read Act and Plan. Beside them, a chip shows who answers,
who helps, and who checks, and opens a picker: the brain switch re-pins the
open conversation through the same door mobile uses; workers and judge are
global and say so.

## Settings, cleaned up

A left nav; Models first, as four rows with the power-user controls behind
one Advanced disclosure; providers as a Connected chip row; the startup
doctor under Advanced › Diagnostics; the desktop listed as the always-on
notification surface it already is.

## Memory

One search with kind facets that hit the engine's stores and scope chips,
hits that say why they matched in plain words, a health strip with the last
tidy, one review queue for duplicate facts and duplicate people, and the
selected memory on a night panel with its sources, a constellation of what it
connects to, Correct, Pin, and Forget with undo. Under a settled reply, the
chat shows "Remembered N things for this", each with a Wrong? that forgets
with undo.

## Not in this release

The backend agent's harness wave (branch `wave/one-gate-and-hardcode-subtraction`)
diverges from main by about 300 files and needs a real merge by its owner. It
is committed and pushed, not shipped here.
