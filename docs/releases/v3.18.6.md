# Clementine 3.18.6

This update brings the new Home experience to desktop and mobile and improves how Clementine discovers tools, prepares plans, and carries approved work into execution.

- Personalize Home with editable layouts and Space tiles, with the updated chat experience alongside your work.
- Plan with clearer progress, relevant memory, and current tool information. Approved execution keeps the reviewed objective and checks current evidence.
- Recover from interrupted model responses while preserving completed work. Persistent connection problems produce a specific continuation request.
- Improve tool discovery, account handling, and provider authentication refresh. Concurrent searches retain each other’s results, and renamed MCP tools refresh correctly.
- Recognize completed Space writes after optional arguments are normalized, and publish finite verified research results as complete so delivery can finish.
- Correct graph classification so host consent guidance does not turn local work into an external-write requirement.

Available for Apple Silicon and Intel Macs. Both installers are signed and notarized. This release does not include a Windows installer.

Validation includes a live GPT Terra / Grok Plan-to-Execute journey, controlled interruption and duplicate-write checks, and fresh-install/restart/replay verification. These checks cover specific journeys; they do not imply that every long-running task will complete without user input.
