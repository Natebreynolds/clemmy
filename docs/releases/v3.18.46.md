# v3.18.46 — Clem keeps going: a yes is the work, a failed call finds its next door, and nothing ends unfinished

**No database migration** (harness schema stays at 98). The Mac build comes
from the release workflow (signed and notarized). The Windows x64 build of the
same commit is qualified by the private Windows pipeline from this tag,
**unsigned** until a code-signing certificate exists.

## Never a dead end

- **"Yes" does the work.** When Clem asks "Shall I proceed?" and you answer,
  the turn now carries her question as its task. Before, a short reply ran on
  its own word: no action, no check, a restatement delivered as the answer.
- **A failed call carries its next door.** Whatever the tool, a failure comes
  back to Clem with what kind of failure it was in plain words and what to do:
  retry once for a passing fault, take another tool or one search for the
  outcome, or ask you only for what only you can supply. A sign-in problem or
  a policy refusal is said plainly, never worked around.
- **A page that can't be read one way says so and names the other doors.** A
  bot check or a script-built page no longer comes back as raw HTML; the
  browser and a connected page reader are named next, and in a batch one
  unreadable site is skipped with its reason while the others continue.
- **A browser that won't answer is explained.** On Windows, Chrome that isn't
  running with remote debugging used to surface as an error code; it now says
  what that means and what else can read the page.
- **A reply that ends on something undone is sent back for the way forward.**
  Both completion checks now treat "it was refused, it remains unfinished"
  with no next way and no reason as incomplete, never as done or blocked.

## Fewer hoops for her own tools

- **The approval card is staged by the host.** A command that leaves this
  machine no longer sends Clem to find and call the queue tool: the host
  stages the exact refused command, the checker writes the card's question in
  her words, and she only speaks. Five brain steps become two.
- **Her own tools show how to call them.** The tool catalog now carries each
  built-in's call signature, so a Space refresh or a workflow run no longer
  costs a search per tool.
- **A remembered account rule routes a read in a new chat.** "Only use my
  Scorpion mailbox for Outlook", once remembered, picks the account without
  asking again.

## Honest about what the Mac is doing

- **A locked login keychain is named everywhere.** When the Mac's login
  keychain stops giving out saved sign-ins, a failed workflow run, a failed
  Space section and the tile all say so with the unlock command, and the run
  is followed up once after the unlock.
- **A Space refresh carries a verifiable receipt.** A refresh that landed is
  now covered by the completion check like a dataset save; "needs a look" on
  a clean refresh is gone.
- **A write-constraint check that throws says what threw and asks once more.**
  A scheduled sheet review was refused for two days by a swallowed exception;
  it is now logged, retried once, and the reason reaches the run.

## Known

- The Windows beta is unsigned and installs with the usual SmartScreen step.
