# Clementine 3.18.7

This patch improves recovery during approved-plan execution and fixes the desktop update-repair freeze.

- Keep usable research results when individual returned items report retrieval errors. Item errors remain available for evidence review; they no longer invalidate the entire successful call merely because they appear in item metadata.
- Allow an unresolved read to recover without incorrectly reporting it as completed. Uncertain writes still require reconciliation before repetition.
- Explain which members of a planned collection are missing usable results, so Clementine can repair the upstream work instead of repeatedly rewriting the same synthesis.
- Include current execution dependencies in existing trajectory reviews and clarify how reviewers should steer repeated failed downstream submissions.
- Stop treating a root-owned macOS installation as an automatic update blocker. Native update installation handles privileges; explicit repair failures appear inline rather than opening a synchronous dialog that can freeze the app.

Available for Apple Silicon and Intel Macs. This patch preserves the Home and chat experience shipped in 3.18.6.
