# v3.9.0 — the visibility release: warm recall on every lane, the conversational beat restored, and a chat that shows the work

Release type: feature release. Everything below shipped with deterministic
regression pins and was proven live on a real workspace during the release
session (five separate dev-daemon acceptance passes). Full suite at the cut:
9,285+ tests, 0 failures, both typecheck roots clean.

## Proven tools skip discovery — on both brain lanes

A remembered, proven procedure now pre-exposes its carrier tool at turn
start (Claude lane JIT pin) and proposes its proven MCP server for
conversational asks (Codex/BYO scope recall). Two gates that silently
disabled the warm path are corrected: the bind-tier matcher demanded an
operation token conversational asks never carry, and the composio
schema-fingerprint check consulted a live-catalog cache that is empty
before discovery has run. Advertising is not binding — fail-closed
fingerprint validation stays on binding paths, where live authority is
still required. Measured live on the same question: 43 s → 22 s, seven
model round-trips → three, first tool call was the answer. The tool-choice
store also gained an mtime-keyed parse cache (72 ms → 12 ms per lookup).

## The conversational beat is back

The v3.6 freeze removed the typed read/align/execute preflight expecting
the graph lane to replace it; the graph lane never landed, so v3.7/v3.8
executed consequential asks with zero conversation. Restored with the
freeze-era corrections kept: explicit autonomy hand-offs ("fully
autonomously, no questions") classify pre_authorized and never beat,
questions and reads stay silent, synthetic continuations are suppressed,
and the beat names the proven standard governing the work on both lanes.
Legacy v3.6/3.7 alignment rows keep a one-release compatibility reader.

## Typed capability resolution

Before the model speaks, the runtime resolves the ask against three
structural sources — proven procedures, invalidated procedures (the
failure facts every active-choice matcher hides by design), and the cached
connection registry — and persists a typed capability_resolution event.
The model receives the table as data with a deterministic floor: re-verify
previously-failed paths before relying on them; surface missing
connections, never work around them. Proven live: the resolution surfaced
a July-failed Apify actor AND its proven variant, and the turn's first
tool call used the proven one. Nothing in the control flow names a
provider; an absent registry reads as unknown, never disconnected.

## The chat shows the work

The full visibility wave plus a live content window, fed exclusively by
typed runtime-verified events:

- live delegated-work card with a server-anchored clock and steer-by-reply;
- tool rows named by the runtime-validated dispatch slug ("outlook send
  email", never "composio execute tool"), with read results narrating their
  shape ("12 records · name, website, phone · 'Acme Roofing'");
- files appear as they land — write_file and shell-written (heredoc /
  in-command cd) files emit deliverable_saved with the file's opening,
  rendered as an auto-opening peek pane while live;
- a capability-grounding row ("2 proven tools, 1 needs a re-check");
- results-first collapsed summaries ("3 files saved · 12 tools");
- the live list stays pinned to the newest row; polite live region for
  screen readers;
- the docked panel is "Working now": foreground chat turns are rows
  (deep-linking to their conversation), the badge counts live work you
  cannot currently see, and it still never auto-opens.

## Reliability fixes found by the release testing itself

- A zombie daemon child no longer blocks the singleton lease (the packaged
  app held a defunct child for an hour after an ENOSPC crash loop while
  every restart was refused).
- The send-receipt gates stop demanding receipts local-only work is
  forbidden to produce: daemon meeting-transcript analysis tasks, and chat
  turns whose write destination is an explicit local file/folder, no longer
  block or get their truthful replies rewritten.
- A time-of-day-dependent test pin (whole-record date scan matching
  timestamps after 17:00 Pacific) now scans argument surfaces only.

## Limitations, plainly

- Every turn still pays a ~1.0–1.4 s recall tax: the default embedder is a
  provider network call per query. Local-first embedding space (re-embed
  corpus locally, query locally) is the named next work.
- The read-result glimpse does not yet populate for call_tool-enveloped
  results (the common direct-dispatch shapes are covered and pinned).
- Mobile-web does not yet render the peek pane or grounding row.
- The tool-choice store carries ~100 near-duplicate memos for some
  toolkits, which degrades ranking; consolidation is queued.
