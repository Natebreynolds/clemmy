# v3.18.62 — Clem's checks read less and trust her helpers' real work

**No database migration.** The harness schema stays at 102 and the memory
database at 38, so going back to v3.18.61 needs no backup. The Mac build comes
from the release workflow (signed and notarized). The Windows x64 build of the
same commit is qualified by the private Windows pipeline from this tag,
unsigned until a code-signing certificate exists.

Proven on the installed app: each change below was hotpatched onto the
owner's running Mac (r60c42 and r60c43) and driven live with test emails and
test agents that were deleted afterwards.

## Clem's helpers get credit for what they actually did

When Clem hands pages to one of your saved agents to read, her record of the
helpers' work now includes those reads. Before, a helper that read the page
was recorded as having done nothing, so Clem told you it had not and read the
pages again herself. The same three-page hand-off now takes 12 model calls
instead of 15, a fifth fewer tokens, and about 20 seconds less, and Clem's
answer says what really happened.

## Clem's quality check reads less

The check on Clem's final answer now reads your facts, preferences, standing
rules and the current state from memory, without the instructions that only
tell Clem how to work. On a simple send its memory went from 9.4 KB to 5.7 KB
and the check still passed. Any new kind of memory still reaches the check.

## A rejected claim is not checked twice for nothing

If the check rejects something Clem said and she answers again without doing
any new work, a quick check looks at whether she is still saying the same
thing. If she is, the same finding goes back to her once instead of a whole
new review. New work, a changed answer, or any doubt still gets the full
review.
