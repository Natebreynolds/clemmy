# v3.18.55 — Clem sets up and runs a workflow in one go, connects an app in her own words, and counts instead of paging

**No database migration** (harness schema stays at 99). The Mac build comes
from the release workflow (signed and notarized). The Windows x64 build of
the same commit is qualified by the private Windows pipeline from this tag,
**unsigned** until a code-signing certificate exists. The iPhone app's new
widgets and Watch activity ship as TestFlight build 19.

This release was proven with a standing first-owner scenario battery run
against the installed app on both brains (GPT and Claude): connect an app,
set up and run a workflow, delete with one card, change your mind on a card,
an error-first command-line read, two asks in one message, memory across
chats, and an impossible ask — scored for time, tool calls, cards, runs,
host-written words, failures, and any call billed to a key of yours.
Against the first run of that battery: GPT went from 4 to 8 of 9 scenarios
within budget with no failures and 27% fewer brain tokens; Claude took 47%
less time, half the tool calls and 79% fewer brain tokens; neither brain
made a call billed to your key or spoke in system words.

## Setting up a workflow

- **"Set it up, then run it once" is one step.** The creation test *is* the
  run you asked to see: Clem shows what it returned instead of running it
  again. A one-step calendar pull went from 136 seconds, 10 steps and two
  runs to about 25–35 seconds, 2–4 calls and one run.
- **Today is your today.** `{{date}}` is the date on your clock, and a time
  written after it carries your offset, so "today's events" after 5 PM
  Pacific is no longer tomorrow.
- **An empty day passes.** A source that answered with nothing right now is
  an answer ("nothing there right now"), not a failed test.
- **Direct calls stay direct.** A step that calls one tool runs without a
  model, on every brain (on Claude it used to become a model step on your
  worker key). A step that expects a list gets the list the tool's answer
  carries.
- **Receipts read cleanly.** Steps say what they do ("Calls … directly (no
  AI)"), a passing test no longer warns you to "confirm the tool", and
  deleting several workflows you name is one card; their live runs stop.

## Connecting an app

- **Clem asks in her own words.** "Notion isn't connected yet. Tap Connect
  to authorize it…", with the Connect button and continue/pause choices
  under it, instead of a fixed system sentence.
- **No wrong-app takeovers.** A question Clem asks about something else is
  never replaced by a connect card for an app the search happened to show.

## Answers

- **Counts, not pages.** Asked how many unread emails you have, Clem finds
  the operation that returns the count (exact totals on both brains) rather
  than listing a thousand messages a page at a time.
- **No system words in her voice.** No "ASK:" marker or doubled question,
  no "Just to be sure" when you move on from a card, and a no to a card is
  answered in a plain line.
- Fewer wasted rounds: Clem's own changes go through the right channel, a
  slipped schema cursor answers the tool you named, and a count query with a
  large limit is clamped instead of refused.

## On your phone (from Codex)

- **Configurable large widgets** with one-tap workflow handoff.
- **A compact branded recording activity** in the Watch Smart Stack.
- Today reads more easily, and primary navigation stays reachable from detail
  screens.

## Known

- On Claude, a delete sometimes goes out without `confirm` and is corrected
  on the next call (one extra round, the card is unchanged).

- The first-round prompt is about 30 KB, over its 29.4 KB ratchet; that
  was already true at v3.18.54 (+108 bytes here). A trim pass is next.
- A second Outlook connection on the owner's machine answers 401; Clem says
  so and counts the one that works.
