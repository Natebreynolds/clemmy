# v3.18.22 — continuity, leaner turns, and verifiable work

Mac-only release. This tag was requested while the final local regression run
was still in progress. It is not an assertion that every qualification gate
has passed. The release workflow must pass its packaging, upgrade, signing and
notarization checks before publishing downloadable artifacts.

## What changed

- Reopened conversations wait for current saved history. Reconnection follows
  the complete event snapshot so an older completed answer is not replayed.
  Switching to a specialist explicitly hands over the role while preserving
  conversation facts and decisions. New Chat routing, Today scrolling and
  conversation-specific work panels are repaired.
- Ordinary turns start with a smaller tool list while discovery and deferred
  calls remain reachable. Familiar reads no longer promote all later turns to
  the full delegation surface. Actual delegation and unfinished long work keep
  the tools they need. Ranked memory enters the changing context once; standing
  rules and approval continuations retain the relevant original request.
- Learned operations are checked against the current schema, account and effect
  before use. Remembered targets do not silently become a new request's targets.
- Completion review can retrieve bounded retained evidence pages and preserves
  substantive depth for incomplete read evidence. Corrected claims go back
  through review, served model identity is recorded, and unavailable review is
  never presented as a pass. Reviewer and fallback choices remain the user's.
- Direct and deferred local tools apply the same strict argument contract.
  Stale MCP arguments produce actionable repair before provider dispatch.
  CLI recovery stays in the conversation and respects the targeted command.
- Filtered or paginated results no longer advertise a whole-dataset reference
  as though it represented the selected page. Workflow enable/disable resolves
  exact durable IDs as well as names and refuses ambiguous identities.
- Desktop and phone expose background memory activity and the memory model.
  Maintenance runs in resumable slices or asynchronous workers. Usage retains
  task attribution without assigning unrelated background work to a chat.

## Efficiency and known limits

- The September 27 matched-prompt sample reduced brain input from 265,363 to
  136,596 tokens and brain frames from 13 to 9 relative to that morning's
  hotpatch. Reviewer coverage differed. This is not a certified whole-task
  saving against v3.18.21, and subsequent accuracy work sometimes adds time or
  tokens. No universal latency or cost reduction is promised.
- The unchanged 130-prompt ordinary-conversation benchmark still expects every
  sample to bypass tool/semantic preparation. Its first failure reproduces at
  v3.18.21. Conservative positive-proof routing keeps tools reachable for
  ambiguous requests; restoring the permissive shortcut would reintroduce
  the observed Salesforce failure. This efficiency target remains unmet.
- The production dependency audit reports 17 advisories, including 7 high and
  none critical. The high-severity affected locked versions are unchanged from
  v3.18.21. That does not establish they are unreachable or harmless;
  reachability assessment and compatible updates remain open work.
- Jev remains enabled, but some long live runs had timeouts. Unreported timeout
  usage is not proof that remote work was free. Full usage accounting includes
  attributed reviewer, worker, memory and Jev calls.
- The observed Salesforce credential-readability issue cleared after the owner
  restarted macOS. This release does not claim to repair Keychain credentials.
- Latest physical-iPhone chat-history acceptance is not claimed. The separate
  voice integration branch and the proposed T3 Code integration are not part
  of this release.
- Windows signing remains unconfigured; this tag publishes Mac artifacts only.

Remaining checks must stay visible after the tag. No pending check, known
